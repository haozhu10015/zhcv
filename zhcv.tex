\section{Software}
Below is a selection of my software projects.
A complete list of projects I have led or contributed to is available at \url{https://haozhu10015.github.io/software}.
\begin{itemize}
    \item \texttt{dbcp}: a CVXPY extension for disciplined biconvex programming
    \item \texttt{cvxgenrust}: an embedded code generator for convex optimization problems in Rust 
    \item \texttt{cvxrust}: a Rust implementation of the disciplined convex programming framework; under development
    \item \texttt{jemdoc-rs}: a Rust rewrite of the static site generator \texttt{jemdoc} for creating academic personal websites
    \item \texttt{rlfit}: a Python package for fitting reinforcement learning models to behavior data under multi-armed bandits
    \item \texttt{hiql}: hierarchical inverse Q-learning for behavior characterization
\end{itemize}
